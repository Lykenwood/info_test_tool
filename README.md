# 通知实验室

独立 Android 示例 App。首页每个按钮都会发布对应类型的系统通知：进度条、媒体播放器、60 秒倒计时、来电、聊天消息、长文本、大图片。点按通知中的媒体或来电操作可以看到状态变化。播放器仅模拟媒体状态，不播放声音；来电仅模拟通知，不发起真实通话。

首页可生成随机通知大图标，之后发送的各类通知都会使用当前图标；桌面图标固定。两种进度示例都每秒更新一次：10% 步进约 10 秒完成，1% 步进约 100 秒完成。两种示例都逐次安排下一步，避免通知发布延迟后集中补发造成的跳跃。

用 Android Studio 打开本目录，或运行 `./gradlew assembleDebug`。APK 在 `app/build/outputs/apk/debug/app-debug.apk`。Android 13 及以上首次启动时需要允许通知。建议在真机上逐项检查通知栏；不同厂商系统的样式可能不同。
